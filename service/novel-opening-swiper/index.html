なぜ流行っているか

読書ハードル低下とゲーム的快感の融合。表紙でなく『冒頭の文体』で本を選ぶという新しい視点が支持。

中核機能

  • 古典・名著の冒頭テキスト スワイプUI
  • 引き込まれた本を"タップで購入/図書館予約"
  • 評者コメント・背景情報パネル
  • 読了時間目安表示

収益モデル

アフィリエイト (Amazon・楽天・図書館リンク) での成約手数料。初期推定: 月1,000スワイプ×1%成約×平均15ドル報酬=月150ドル。または、出版社との提携プログラム (新刊紹介料)。

個人での攻め筋（本人＋Claude）

読書層・学生・出版業界へ軽くPR。初期: 無料ユーザー増で月1,000~3,000スワイプ達成。アフィリエイト成約率 1~2% で月150~300ドル。その後、プレミアム『本棚機能・読書進捗管理・SNS共有』月2ドルで+200ユーザー=月400ドル。合算月600~700ドル (月7~8万円)。ただし月20万超はアフィリエイト単価向上 (新刊・高価本へのシフト) やB2B (出版社パートナー報奨金) 必須。現実的には月8~15万円規模で落ち着く見通し。

構築難易度 — 2/5

テキストコンテンツ (古典小説冒頭) は著作権切れのPDFで大量入手可能 (Project Gutenberg等)。スワイプUIは React/Vue で容易。

想定技術スタック

React/Vue.jsProject Gutenberg API (テキスト取得)Amazon/楽天 API (アフィリエイトリンク)

片手間運用性 — 5/5

コンテンツは更新不要 (古典は変わらず)。UI改善・新テーマ追加程度。SEO・SNS拡散で自然流入。

収益到達性（月20万） — 2/5

アフィリエイト単価が低めで、大規模ユーザー数が要る。月20万には月3,000~4,000成約が必要。現実的な個人運用では月10~15万程度に留まる可能性高い。
