なぜ流行っているか

目標管理・習慣化アプリの競争が激化する中で、「AI コーチングで言語化・細分化する」というアプローチが新規性を持つ。セルフ・コンパッションとデータドリブン化のバランスが評価されている。

中核機能

  • 目標から日次タスク への自動分解
  • 進捗トラッキング (自由形式・構造化)
  • AI コーチ による動機づけ・フィードバック
  • 進捗の可視化・リフレクション機能

収益モデル

基本無料 (月 1 目標・月次レビュー) + プレミアム (無制限目標・週次コーチング・エクスポート、月 800 円程度)。推定: 月 3,000 ユーザー×課金率 25%×月 800 円 = 月 60 万円規模

個人での攻め筋（本人＋Claude）

初期は「起業家・キャリアシフト志向者」に特化。個人ブログ・Twitter で目標管理の失敗事例を共有し、解決策として Good Assistant を紹介。月 3,000 ユーザー×課金率 25%×月 800 円で月 60 万円達成。B2B 化 (企業研修向け) で +月 10〜20 万円上乗せ。

構築難易度 — 2/5

目標分解ロジックはプロンプト工学で実装 (Claude との会話形式で十分)。進捗トラッキング UI はシンプルで、Claudeが1週間で MVP 構築可能。複雑な機械学習は不要。

想定技術スタック

Next.js / React (フロントエンド)Node.js + Express (バックエンド)Claude API (目標分解・コーチング会話)PostgreSQL (ユーザー・進捗 DB)Stripe (決済)Vercel (ホスティング)

片手間運用性 — 4/5

AI コーチ部分は自動化、ユーザーサポートはメール対応のみ。コンテンツ (目標テンプレート・ガイド) の定期更新は月 5 時間程度。スケール後もシステムが自動で回る。

収益到達性（月20万） — 4/5

自己啓発層は月 800 円の課金に抵抗感が低い。LTV が高く、習慣化すれば解約率が低い。ニッチながら確実に稼げる層が見える。
