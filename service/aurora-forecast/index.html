なぜ流行っているか

NOAA/地磁気データをリアルタイム取得し、UI美麗に可視化する Aurora チェッカー。SNS で季節ごとに話題になり、Nordic圏・北米での利用が顕著。

中核機能

  • リアルタイム地磁気指数 (Kp指数) 取得
  • ユーザー位置情報ベース可視性判定
  • 美しいインタラクティブマップ表示
  • プッシュ通知 (可視チャンス時)

収益モデル

freemium: 基本無料、高精度予報・通知機能は有料; または広告 + 天体望遠鏡・旅行業者へのアフィリ

個人での攻め筋（本人＋Claude）

基本無料で北米・欧州のスマホユーザーを大量獲得。プッシュ通知で「今夜見られる可能性!」と送信し使用頻度を高める。月額 2〜4USD のプレミアム (精度向上・高度な予測) で 30〜40%の ユーザーから収益。アフィリ: Aurora ツアー・望遠鏡業者へのリンク経由。北欧観光局とのパートナーシップで参考データを充実。

構築難易度 — 1/5

NOAA の公開 Kp指数 API + OpenWeatherMap + 簡単な計算式で位置情報ごとの可視性予測。地磁気・天文の高度な計算は既存公開モデルで代替可能。本人+Claude で 1〜2週間で構築。
