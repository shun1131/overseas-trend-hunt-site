  • 予定・タスク自動管理
  • SMS/電話への統合

収益モデル

月額サブスク（Starter 9.99ドル / Pro 19.99ドル推定）/ プレミアム通話オプション

個人での攻め筋（本人＋Claude）

多忙なビジネスパーソンは秘書を雇いたいが高額。AI 秘書を月10ドルで提供。初期は「予定管理」「メモ記録」に限定し、やがて「メール要約」「優先度判定」等に拡張。Reddit・ProductHunt で認知を広げ、月額10ドル×300人で月3,000ドル超

構築難易度 — 3/5

iMessage API・通話 API (Twilio 等) との連携が複雑。Claude+Twilio+Apple iMessage API で実装可だが、iOS App 開発・通話システムは中程度の専門性が要る
