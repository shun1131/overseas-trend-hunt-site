なぜ流行っているか

美術館オープン API(Metropolitan/V&A等)の進展。文化遺産デジタル化急速化。学生・教育者・アート愛好家層が『ニッチだが確実に使う』検索基盤として需要

中核機能

  • 複数美術館 API 統合検索
  • 作品メタデータ(年代・作家・技法)
  • コレクション共有機能
  • 教育向けリソース(引用・授業素材)

収益モデル

基本無料 + 課金: 教育機関向けライセンス($50-200/月)、利用者向け高度な検索/保存 ($4.99/月)、美術館 API ホスティング受託

個人での攻め筋（本人＋Claude）

初期リリースは検索 + 基本結果表示で最小化。美術館愛好家・美術教育者向けに Reddit/Twitter で口コミ。月額無料で検索エンジンとして固着。教育機関向けライセンス($100/月 × 50-100 校)で月 5-10 万。プレミアム検索オプション($5/月 × 1000 人)で月 5-10 万。合算月 15-20 万で目標到達。Patreon でアート パトロン層の寄付も補助金化
