なぜ流行っているか

Claude Codeの普及に伴い、セッション管理の煩雑さが痛点化。シンプルなセッション履歴UXが重宝されている。

中核機能

  • Claude Code セッション履歴表示・検索
  • ワンクリック再開
  • セッション時間・トークン使用量の記録
  • コンテキスト保持の自動化

収益モデル

フリーミアム ($4.99/月 Pro、セッション無制限保存)、またはアップセル (Enterpriseで $29/月 団体管理)

個人での攻め筋（本人＋Claude）

初期は無料版で開発者コミュニティから認知を獲得。月$4.99のPro版を月500人が購入なら月$2,500。月20万に到達するには、企業向けのセッション共有機能 ($29/月) を追加し、月60社の契約を見込む。

構築難易度 — 2/5

Claude APIとローカルセッション管理のみで実装可能。UIは単純で、Claudeが容易に構築できる。複雑な同期ロジックは不要。

想定技術スタック

Electron (デスクトップ)Claude APISQLite (ローカルDB)React

片手間運用性 — 5/5

ユーザーのセッション自動保存が主な機能で、バックエンド処理も軽い。放置でも正常に動作し、スケール時の手間もほぼなし。

収益到達性（月20万） — 3/5

開発者向けは継続課金の心理ハードルが低い (月数ドル)。だが顧客数が限定的で、月20万は月800〜1000Pro購入ユーザーが必要。
