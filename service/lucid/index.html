なぜ流行っているか

アクセシビリティ × 生産性の注目が高まる中、音声駆動の「思考の可視化」に需要。プログラマー・設計者が設計会議の音声メモを即図化できる点で差別化。

中核機能

  • 音声→テキスト変換 (Whisper など)
  • 粗いテキスト→構造化ドキュメント化
  • Mermaid/PlantUML 図式自動生成
  • エディタで後編集可能

収益モデル

SaaS: 無料枠 + 月額 (月5〜15USD 想定。API使用量ベース)

個人での攻め筋（本人＋Claude）

初期ターゲットは「プログラマー・システムアーキテクト・プロジェクトマネージャー」。音声→図表は「会議終了後にすぐSlackで図を共有」という使い方で広がる。Dev コミュニティ (Reddit/HN/Dev.to) で無料ツール版を先行リリース。月額9USD の「チーム共有プラン」で収益化。競合 (Excalidraw等) との差別化は「音声駆動」と「自動構造化」。

構築難易度 — 2/5

Whisper/Claude でテキスト化と構造化は実装可能。Mermaid/PlantUML への図表変換も既存ライブラリ。エンドツーエンドで本人+Claude で完成。

想定技術スタック

Next.jsOpenAI Whisper (or local)Claude API (構造化変換)Mermaid.js / PlantUMLAWS/Vercel

片手間運用性 — 5/5

クラウド音声API + LLM処理で完全自動。手作業は統計・UX改善の定期ループのみ。ほぼ放置可能。

収益到達性（月20万） — 4/5

開発者層は課金意欲が高く、月額 5〜10USD ×200〜300ユーザーで月20万に届きやすい。APIコスト管理が課題だが、ユーザーの音声ファイル数を制限することで調整可能。
