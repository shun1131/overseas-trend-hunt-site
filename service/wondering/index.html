なぜ流行っているか

ゲーム的な学習体験の需要が高まり、言語学習以外への応用が急拡大。短時間継続学習が次の成長軸。

中核機能

  • 5分以内のマイクロレッスン
  • ゲーム的な進捗管理・バッジ
  • 複数スキルジャンルへの対応
  • AI講師のフィードバック

収益モデル

フリーミアム (月$4.99で広告除去・無制限レッスン)、または企業向けB2B (月$999〜 社員研修)

個人での攻め筋（本人＋Claude）

初期は1ジャンル (e.g. Python基礎) に特化。月500有料ユーザー×$4.99 = 月$2,500。企業向けB2B (月$299) を月50社に販売で月15,000。複数ジャンル追加と企業採用で月20万。初期3〜6ヶ月は月$5K程度から開始。

構築難易度 — 2/5

クイズ・ビデオ・AIフィードバックの統合で、複雑度は中程度。Claudeが主軸で、コース設計と質問生成に向く。レッスン動画は外注またはテンプレート再利用で対応。

想定技術スタック

React/Next.jsOpenAI API (フィードバック生成)Stripe (決済)PostgreSQL

片手間運用性 — 3/5

ユーザーサポートとコース品質の継続改善が必要。特に初期段階でのコース拡充は手作業多め。スケール後は分析・最適化で手間が減る。

収益到達性（月20万） — 3/5

フリーミアムは学習層が無料利用多め。企業向けB2Bが利益を支えるが、営業が必要。小規模でも月20万に到達は可能だが、段階的成長が要件。
