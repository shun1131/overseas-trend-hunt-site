なぜ流行っているか

RPA・自動化の民主化が加速する中で、コード不要で「自分の作業を AI に任せる」という単純なコンセプトが注目。Claude Code と同等の行為能力を UI で実装した点が評価されている。

中核機能

  • 自然言語による作業指定
  • ブラウザ自動操作 (スクリーンショット認識)
  • ワークフロー保存・繰り返し実行
  • 複数ブラウザタブ間での連携

収益モデル

基本無料 (月 10 作業まで) + プレミアム (月 500+ 作業・優先実行・カスタムワークフロー、月 1,500 円程度)。法人向け SaaS (月 10,000 円〜)。推定: 月 2,000 ユーザー×月課金率 15%×月 1,500 円 = 月 45 万円規模

個人での攻め筋（本人＋Claude）

初期は「給料計算表の自動入力」「定期レポート作成」など 3〜5 個の高頻度タスクに特化。この分野なら Claude Code でも実装可能。月 2,000 ユーザー×課金率 15% で月 45 万円規模を狙う。その後、業界別テンプレート化で多業種展開。

構築難易度 — 3/5

スクリーンショット認識・ブラウザ自動化 (Playwright 等) は Claudeで実装可能だが、複数の UI 構造への対応や誤り処理が複雑。MVP (特定サイトに特化) なら 3 週間程度、汎用化には 2〜3 ヶ月要。

想定技術スタック

React (フロントエンド)Node.js + Express (バックエンド)Playwright または Selenium (ブラウザ自動化)OpenCV / Claude Vision (スクリーンショット認識)Redis (タスクキュー)PostgreSQL (ワークフロー保存)

片手間運用性 — 3/5

ユーザーの作業パターンが多岐に渡り、予期しないエッジケース対応が頻発。初期段階では週 10 時間程度のサポート・改善が必要。スケール後は改善スクリプト自動化である程度軽減可能。

収益到達性（月20万） — 4/5

業務効率化の需要は恒常的で、月 1,500 円の課金障壁は低い。SaaS 特性で LTV が高く、チャーンさえ抑えられれば月 20 万到達は容易。
