なぜ流行っているか

言語学習者の『辞書引き手作業』を完全自動化。アニメ・ドラマ・小説で実用学習できるツールとして急成長。

中核機能

  • テキストの即座に単語をタップ→意味表示
  • 音声読み上げ(ネイティブ発音)
  • 文法解説・文脈学習
  • 進度トラッキング(習得単語管理)

収益モデル

フリーミアム。基本無料(月5本まで)+有料版(無制限・オフライン・カスタム教材)月1,000円。また言語学校・オンライン講座とのパートナー(生徒割引紹介)で手数料。

個人での攻め筋（本人＋Claude）

日本語学習者向けコミュニティ(Reddit r/LearnJapanese, Twitter言語学習タグ)で初期ユーザを獲得。YouTube動画『このツールでアニメを字幕なしで理解』で認知を広げ、月1,000~5,000ユーザ獲得を狙う。有料版(月1,000円)は、多読学習コース販売と連携し、月100~200ユーザの課金で10~20万到達。また言語学校・Duolingo的アプリとのアフィリ紹介(月500~1,000円/推薦)で上積み。

構築難易度 — 3/5

日本語・中国語の形態素解析(MeCab/Janome等)とテキスト・音声の統合が中核。既存ライブラリで大半をカバーできるが、文法解説の質(LLM統合)とネイティブ音声合成(TTS)の精度で競争力が決まる。Claudeで骨組みは組めるが、言語の細部で手調整必須。

想定技術スタック

React (フロントエンド)Node.js + FastAPI (バックエンド)MeCab/Janome (日本語形態素解析)Google Cloud TTS (音声合成)PostgreSQL (ユーザ・学習記録DB)AWS S3 (教材ホスティング)

片手間運用性 — 3/5

TTS・音声CDNは外部頼み(Google Cloud TTS等)。ユーザが教材をアップロードするため、コンテンツ審査(著作権)が散発的に手作業。学習者からのQ&A対応も多い。多言語対応なら運用工数増。

収益到達性（月20万） — 4/5

言語学習は市場が大きく(世界規模)、月1,000円の課金障壁は低い。個人学習者でも確実に価値を認識。月200ユーザ×1,000円でも月20万。英語対応は難しいが、日本語・中国語に絞れば差別化できる。
