なぜ流行っているか

リモートワーク化で、小さな生産性改善ツールが重宝される。Todoist ユーザーの痒いところに手が届く拡張。

中核機能

  • Todoist との連携
  • サブタスクのインライン表示
  • クイック編集・チェック機能
  • 同期の自動化

収益モデル

Chrome Web Store 有料版（$2.99）、またはサブスク（月$1.99）

個人での攻め筋（本人＋Claude）

Chrome Web Store で$2.99 の買い切り版をリリース。Todoist ユーザー向けSNS（X, 公式フォーラム）で自然拡散を狙う。初期は無料版で機能制限し、月500DL × $2.99 で月1,500$を見込む。サブスク化で月$1.99 に下げ、ユーザー数を3倍に増加させることで月6,000$到達可能。付加機能（カレンダー連携、優先度AI分析）で差別化。

構築難易度 — 1/5

Todoist API を使用した連携が中心。Chrome拡張開発は標準的で、Claudeで容易。DOM操作も基本的。

ブラウザ拡張なので利用者側のローカル実行。サーバー・運用コストはほぼゼロ。

Todoist ユーザーベースが大きく（数百万人）、ニッチながら課金意欲が高い。月500本の売上は現実的で、サブスク化で月20万に到達可。
