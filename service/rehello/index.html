なぜ流行っているか

リモートワーク化で疎遠になった人間関係の修復が課題。人脈管理アプリへの需要が高まっている

中核機能

  • 連絡先の詳細メモ (趣味・家族・共通経験)
  • 定期再接続のリマインダー
  • 連絡テンプレート提案
  • 人間関係グラフの可視化

収益モデル

フリーミアム (基本無料、有料プラン月2.99-5.99ドル)。プレミアムは無制限連絡先・AI提案・分析

個人での攻め筋（本人＋Claude）

人脈管理に悩む内向的なプロフェッショナル (フリーランス・営業職) をターゲット。月3.99ドルのサブスク。月5000-7000ユーザー到達で月20万達成。初期は LinkedInやTwitterで『人間関係の負担を減らす』メッセージでリーチ

構築難易度 — 2/5

WebアプリはReact + Node.jsで実装。CRM概念を簡略化。Claudeで十分対応可能。モバイルはReact Nativeで対応

想定技術スタック

React + Node.jsPostgreSQL (連絡先DB)メール配信 (Sendgrid)リマインダーシステム

片手間運用性 — 4/5

初期構築後の保守はバグ修正とUI改善のみ。自動通知とメール配信で継続的価値を提供

収益到達性（月20万） — 3/5

SaaSの課金意欲はあるが、市場が限定的。月5000ユーザー以上の獲得に時間要する
