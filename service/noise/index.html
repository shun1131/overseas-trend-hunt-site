なぜ流行っているか

UGC（ユーザー生成コンテンツ）の急速な商業化。素人動画に価値が出始め、プロ化なしに収入化できる仕組みへのニーズ爆発。

中核機能

  • スマホ動画簡単アップロード
  • AI コンテンツ評価・推奨
  • レディ・自動マネタイズ
  • クリエイター手数料（70%～80%）
  • アナリティクス・リーチ分析

収益モデル

プラットフォーム手数料（20～30%）、スポンサーシップ仲介

個人での攻め筋（本人＋Claude）

初期は YouTube ショート・TikTok 二次投稿向けプラットフォーム。手数料 30% で UGC クリエイターを集め、広告主開拓は後付け。月100～200 クリエイター × 平均 $100/月支払い ＝ 月3～6万手数料。スケール後は Facebook/Google ネットワークへの API 販売で上乗せ。

構築難易度 — 2/5

動画UGC 集約・課金は SaaS の基本。ただし広告主開拓・マッチング精度がビジネス成功を左右。Claude でプラットフォーム本体は作れるが、市場開拓は別。

想定技術スタック

React/Next.jsNode.js/DjangoFFmpeg（動画トランスコード）Google Cloud Vision（コンテンツ評価）Stripe（支払い）

片手間運用性 — 3/5

プラットフォーム運用にはコンテンツモデレーション・支払い管理・広告主関係が必要。自動化部分と手作業部分の混在。

収益到達性（月20万） — 3/5

プラットフォーム手数料依存。ユーザー母数と広告主発掘のペースが収益性を大きく左右する。初期段階では月20万の到達難。
