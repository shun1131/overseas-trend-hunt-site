なぜ流行っているか

個人が社会貢献 AI エージェントを複数運用し、その行為の透明性(receipt)を公開する新しい社会実験がHNで話題。AI の倫理・透明性への関心の高まり。

収益モデル

個人での攻め筋（本人＋Claude）

本家Aura Engineは概念実装段階。日本で『地域貢献 AI エージェント』として、各市区町村の公開データ(ゴミ拾いスポット、道路補修報告)を自動化。月額サブスク形式で地方自治体や NPO 向けに販売。エージェント 1 体/月$30-50 で 50-100 体受託を目指し、月20万達成。

構築難易度 — 3/5

自治体 API (NYC 311)連携、複数エージェントの並行管理、透明なレポート生成はClaudeで実装可能だが、civic alerts の解析と appropriate tasks の判定ロジックが複雑。

想定技術スタック

NYC Open Data API/311 連携Claude API + autonomous agentsReact/Next.js フロントエンドFirebase/Supabase ユーザー・エージェント管理

片手間運用性 — 3/5

エージェント実行は自動だが、タスク品質の監視、ユーザーからのカスタムリクエスト対応、レピュテーション管理に手間。

収益到達性（月20万） — 3/5

社会貢献色が強く、営利色の強調が難しい。ただし自治体・NPO 向けサービス化で月20万は現実的。継続的なプロダクト改善が必須。
