なぜ流行っているか

AIエージェントが科学論文を正確に参照する需要が急速に拡大。従来の学術検索をエージェント向けに再設計したツールが市場を開拓中

中核機能

  • 2億3600万論文の横断検索
  • エージェント向けAPI・言語
  • 引用・参考文献自動整理
  • コンテキストウィンドウ最適化

収益モデル

推定:API月額99ドル~/研究機関向けサイトライセンス/査読補助SaaS

個人での攻め筋（本人＋Claude）

既存学術検索API (arXiv等) をラッピング・最適化し、エージェント向けに再包装。初期は『AI研究者向け論文検索API 月額99ドル』として販売。やがて企業R&D・大学向けサイトライセンス月額999ドル超で展開。月20万は20社程度の導入で到達可

構築難易度 — 4/5

大規模論文データベース・インデックス構築に専門知識が要る。Claudeが検索エンジン本体を完全構築は難しく、既存APIラッピング戦略が現実的

想定技術スタック

Elasticsearch/Milvus (ベクトル検索)Python/FastAPI大規模データセットClaude/OpenAI API

片手間運用性 — 4/5

検索エンジン提供側の運用は軽い。バックエンド(インデックス更新)は定期自動実行で対応可

収益到達性（月20万） — 3/5

ニッチ(学術・AI研究者層)であり、広い市場ではない。ただしニーズが確実で単価が高いため、小規模でも採算可能
