なぜ流行っているか

AI 音声認識・要約の精度向上により、雑談・思考をそのまま価値あるメモに変える需要が急速に高まっている

中核機能

  • 音声入力のリアルタイム認識
  • 自動要約・キーポイント抽出
  • 保存・検索・タグ付け機能

収益モデル

フリーミアム (月 10~30 分まで無料、その先有料) / サブスク (月 5~15 ドル無制限) / B2B (チーム用ライセンス)

個人での攻め筋（本人＋Claude）

Claude で音声→テキスト→要約パイプラインを実装。Whisper + Claude API で自動処理。初期: 無料版で集客。有料: 月 500~1,000 円×300 ユーザー。B2B (営業 / カウンセリング業界) に月 5,000~20,000 円。月 20 万達成容易

構築難易度 — 1/5

Claude + Whisper API / Google Speech-to-Text で音声認識。要約は GPT/Claude で自動化。Web UI は標準フレームワークで容易

想定技術スタック

Next.js / ReactWhisper API / Google Speech-to-TextClaude / GPT 要約 APIFirebase / Supabase (バックエンド)

片手間運用性 — 5/5

完全自動化: 音声入力 → API 処理 → 自動保存。ユーザーサーバー運用の手間はほぼゼロ。スケーリングは API 側で吸収

収益到達性（月20万） — 5/5

音声メモの市場は大きく (Otter.ai の成功例)、小額課金でも拡がりやすい。API 従量コストは月 3,000~5,000 円程度で利益率 70% 超
