なぜ流行っているか

SNSマーケターと研究者の『バイラル源流追跡』ニーズ。インフルエンサーはオリジナルクレジット獲得に関心。

中核機能

  • 投稿のオリジナルソース特定
  • リツイート/リシェア経路の可視化
  • インフルエンサー経由での拡散追跡
  • タイムラインビュー

収益モデル

Freemium型。無料版(直近1週間のデータ)、Pro(月額2000円・全履歴・APIアクセス)。メディア/ブランド向けエンタープライズプラン。

個人での攻め筋（本人＋Claude）

Twitter/X上でコンテンツクリエーターと研究者へのPR。『あなたの投稿はどう拡散した?』のバイラルループ自体を作る。無料版の高利用で信用構築→Pro乗換。SNS研究者向けAPIプラン(月5000円)で追加収益。50社×月2000円+10社×月5000円で月15万。

構築難易度 — 3/5

TwitterのグラフAPI・検索API連携は必須。大量データのグラフ化と展開計算が必要。Claudeで可能だが、API制限対応とスケーリングに工夫が要る。

想定技術スタック

Twitter API(Graph API v2)React/D3.js(グラフ可視化)Python/Node.js(バックエンド)PostgreSQL/Neo4j(グラフデータベース)

片手間運用性 — 4/5

バックエンド定期実行で自動データ取得。フロント表示は静的。更新負荷は初期設定後は軽い。

収益到達性（月20万） — 3/5

個人クリエーターの課金意欲は低い。企業/メディア向けに軸足を移す必要があり、BtoBは工数要。到達は容易でない。
