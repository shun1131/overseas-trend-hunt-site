なぜ流行っているか

Superhumanが高額（月額$30+）で導入障壁が高く、オープンソース型の軽量メール自動化ツールへの需要が急速に高まっている。生産性ツールの「オープンソース化」トレンドも追い風

中核機能

  • AIベースの自動ラベリング・振り分け
  • カスタムルールエンジン
  • バルク操作・自動返信テンプレート
  • 一括アーカイブ・スヌーズ機能
  • 複数メールアカウント対応

収益モデル

フリーミアム型（基本無料＋プレミアム機能）、月額$5～$15。または企業向けホスティング版・ホワイトラベル版販売。推定：月額課金で月商15～30万円規模

個人での攻め筋（本人＋Claude）

オープンソース版を GitHub で無料提供し、「セルフホスト版」と「クラウド版（有料）」の2層構成にする。クラウド版は月額$12で、セットアップの手間を消したい法人・個人事業主を狙う（推定：500～1,000人で月商6～12万円）。並行して企業向けホワイトラベル版（カスタマイズ・API制限なし）を月額10,000円～で販売。コンテンツマーケティングとして「メール効率化」ブログ・YouTubeで流入を作る

構築難易度 — 2/5

Gmail/Outlookの標準APIを使用、バックエンドはNode.js/Pythonで実装可能。AIの振り分けロジックはClaudeで対応でき、複雑な機械学習は不要

片手間運用性 — 4/5

メール自動化は一度セットアップすれば自動で回転。サーバーもサーバーレスで管理負荷は小さい。ユーザーサポートはコミュニティが支える可能性も

収益到達性（月20万） — 4/5

メール管理は全てのビジネスパーソンの共通課題。月額$12程度は認知が広がれば十分到達可能。オープンソース→有料版への自然な漏斗も強み
