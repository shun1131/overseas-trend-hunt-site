なぜ流行っているか

思考の外在化と可視化が同時進行するニーズが高まっている。ブレーンストーミング・企画立案の効率化。

中核機能

  • 音声入力による思考キャプチャ
  • NLP による自動概念抽出・マッピング
  • リアルタイム図解（マインドマップ的表現）
  • 編集・エクスポート機能

収益モデル

サブスク（月$9.99 で長時間録音・高度な分析）、またはB2B版（チーム機能付き月$49）

個人での攻め筋（本人＋Claude）

初期は個人向け無料版で月500ユーザー獲得。口コミから月$9.99 のプレミアム版（録音時間制限解除・クラウド保存）へ段階的移行。月200人 × $9.99 で月2,000$。同時にSlack連携・Teams連携でB2B版（月$49/チーム）を展開し、企業顧客5社で月$245。付加的に API 提供（月$199/開発者）で補完。

構築難易度 — 2/5

音声認識（Whisper等）+ NLP（Claude）で概念抽出。グラフ可視化（vis.js等）で描画。Claudeで実装可能。

想定技術スタック

Whisper API（音声認識）Claude API（概念抽出・マッピング）vis.js/D3.js（グラフ可視化）Next.js + FastAPIAWS Lambda

片手間運用性 — 4/5

API 利用型なのでサーバー負荷は軽微。ユーザー音声処理は AWS Lambda で自動スケール。運用放置可能。

収益到達性（月20万） — 4/5

認知系ツールで付加価値が高く、個人・法人双方で課金意欲が高い。月20万到達は十分現実的。
