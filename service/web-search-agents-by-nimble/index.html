なぜ流行っているか

大規模LLMの登場でエージェント型ツール需要が拡大。手作業リサーチの自動化ニーズが急増

中核機能

  • 複数キーワードの並行検索
  • Webスクレイピング自動化
  • リサーチ結果の自動集計・要約
  • 学習機能（検索戦略の最適化）

収益モデル

SaaS月額制推定。月3,000〜10,000円。エージェント呼び出し回数による従量料金も混在。

個人での攻め筋（本人＋Claude）

企業のリサーチチーム向け（月10,000円×20社）。データアナリスト・マーケターの自動化。初期はTwitter/LinkedIn で導入事例を発信。

構築難易度 — 3/5

Web検索API（Serp等）、LLMによる戦略立案、スクレイピング制御など複数要素が必要。Claude + Python で実装可能だが、検索品質・スケーラビリティがやや困難。

想定技術スタック

SerpAPI/Perplexity APIClaude APIPython（バックエンド）React（フロント）キューシステム（Celery/Bull.js）

片手間運用性 — 3/5

エージェントの動作監視・エラーハンドリングが必要。スクレイピングの違法性リスク管理も手間。

収益到達性（月20万） — 3/5

B2B単価は高いが、営業難度が高く、ユーザー獲得が困難。競合（Perplexity等）との差別化が必須。
