なぜ流行っているか

AIエージェントの『暴走』懸念が高まる中、『 approval-first 』という安全設計が個人事業主・小規模スタートアップから注目。意思決定の透明性を保ちながらAI自動化するニーズ。

中核機能

  • 承認ベースのエージェント実行
  • タスク・ワークフロー設定
  • 実行ログ・監査履歴
  • 複数エージェント統合

収益モデル

SaaS型月額制。無料版：試用1エージェント、Pro版：月$49/3エージェント＋無制限実行、Enterprise：カスタム。

個人での攻め筋（本人＋Claude）

日本の個人事業主・スタートアップ向けに『安心のAI自動化』として展開。Twitterで『AI 暴走防止』『安全な自動化』をテーマに営業。初期は月$49=¥6,000 で、月100ユーザー×¥6,000＝月60万。エージェント数制限で上位プラン誘導。

構築難易度 — 2/5

エージェント呼び出し＋承認待機＋ワークフロー定義が主体。複雑な機械学習なし。既存エージェント API（Claude・OpenAI）をラッパーし、承認UI を Next.js で実装。Claudeで単独構築可能。

想定技術スタック

Next.js / ReactClaude API / OpenAI APIPostgreSQL（ワークフロー・ログ）Bull Queue or similar（非同期キュー）Stripe（課金）

片手間運用性 — 5/5

承認待ちはユーザーが主体。バックエンドは完全非同期キューイング。運用コストほぼゼロ。

収益到達性（月20万） — 5/5

安全・透明性は価値が高い。月¥6,000は安い。100ユーザーで月20万超え容易。スケール性高い。
