なぜ流行っているか

ノスタルジア需要。Webの歴史への興味。シンプルで思わずやり続けたくなるUI。Internet Archiveの認知向上。

中核機能

  • Wayback Machineランダムサンプリング
  • 懐かしサイトのビジュアル再現
  • ポップアップトリビア表示
  • シェア機能
  • タイムスタンプ表示・リンク

収益モデル

広告なし（非営利寄付型）+ Internet Archive への募金呼びかけ + オプション：有料ガイドブック・ポストカード販売

個人での攻め筋（本人＋Claude）

広告ナシで純粋なコンテンツ公開。Internet ArchiveへのPRと募金の関連性を強調。ノスタルジアコンテンツとしてTikTok/YouTubeで定期配信し集客。月商は難しいが、ポストカード・ガイドブック販売で小売収入。あるいはスポンサーシップ。月商10～15万が現実的。

構築難易度 — 1/5

Wayback Machine API + ランダム選択 + UI表示のみ。JavaScriptで完全実装可能。複雑な処理なし。

完全にスタティックサイト。一度作ればほぼメンテ不要。トラフィック急増時もCDN対応で自動スケール。

収益到達性（月20万） — 1/5
