なぜ流行っているか

カスタマーサポートの自動化とAI統合が急速に進み、既存チャットツール（Zendesk等）とAIの連携が求められている。MCPプロトコルの標準化も背景。

中核機能

  • チケット自動解析
  • LLM統合回答生成
  • 既存CRMとの連携
  • 品質チェック機能
  • 学習・改善ループ

収益モデル

SaaS月額制（スタート$19/月、プロ$79/月）＋処理チケット数による従量課金＋Slack/Teams等の連携追加料金

個人での攻め筋（本人＋Claude）

スタートアップ・SMB向けに、Producthunt・SaaS掲示板で認知獲得。月50チケット処理できる無料プランで初期段階は拡大。その後$19/月へのアップセルで、月400社×$50平均で月商20万円達成。チケット処理の自動化により顧客満足度も向上。

MCP (Model Context Protocol) はClaudeが標準対応。チケットシステムとの連携も既存APIで実装可能。技術的ハードルは低め。
