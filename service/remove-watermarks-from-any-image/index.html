なぜ流行っているか

生成AIの逆用。素材の再利用・クリエイティブの短時間化が需要。一方で著作権懸念もあり規制の目も

中核機能

  • ドラッグ&ドロップでウォーターマーク検出
  • 自動削除・修復（inpainting）
  • バッチ処理対応
  • 品質設定（低/中/高）

収益モデル

従量制（1画像$0.50）またはサブスク（月$20で月100枚）。API販売も可

個人での攻め筋（本人＋Claude）

初期はSimple UI（アップロード＆削除ボタンのみ）で PoC 作成。Twitter/TikTok でデモ動画を大量発信。デザイナーコミュニティ（Dribbble・Behance）に直接アプローチ。APIコストを抑えるため初期は手作業で高品質版を用意し、信頼を獲得後に自動化移行

構築難易度 — 3/5

inpaintingモデルの実装が必要。OpenAI API・Replicate等でのモデル利用は可能だが、品質向上には微調整が必要

想定技術スタック

OpenAI DALL-E Inpaint / Stable Diffusion API（Replicate等）Next.js + VercelStripe（支払い処理）AWS S3（画像保存）

片手間運用性 — 4/5

一度APIを接続すれば自動。ただしスケールに応じた費用管理が手動

収益到達性（月20万） — 3/5

著作権リスク＆API費用がかかるため利益率は低い。月5,000アップロード（従量）で月12-15万程度が現実的。ただし複数の付加機能（背景生成など）で平均客単価を上げる余地あり
