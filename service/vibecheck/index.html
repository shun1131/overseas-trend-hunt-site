なぜ流行っているか

AI コーディングエージェントの台頭で「LLMコピペPR」問題が露呈。企業内コード品質管理への需要が急増している。GitHub Actions との統合で導入が簡単。

中核機能

  • PR コード理解度テスト自動実行
  • Claude/LLM による簡潔な質問生成
  • マージゲート (テスト失敗で PR ブロック)
  • 自社ホスティング対応

収益モデル

SaaS/エンタープライズライセンス: チーム数 or PR 数ベースの従量制 (推定：月10〜50USD)

個人での攻め筋（本人＋Claude）

初期ターゲットは「AI エージェント導入による code review 不安」を抱える スタートアップ・中小開発チーム。LinkedIn や Dev.to で「AI時代のコード品質」をテーマに記事を発信。GitHub Marketplace での無料プラン公開で導入ハードル下げ、月額 15〜25USD のチームプランで収益。セルフホスト対応で大企業の導入を加速。
