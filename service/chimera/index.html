なぜ流行っているか

副業・個人活動が増える中で、同志を見つけて集団で成長する「コホート学習」が注目を集めている。ZippeやEdmodoなど既存プラットフォームは教育寄りだが、本サービスはビジネス・学習の両立を目指す地域コミュニティ型で差別化している。

中核機能

  • 地域別の参加者マッチング
  • コホート形成の自動サジェスト
  • 進捗共有・報告機能
  • イベント開催サポート

収益モデル

月額サブスク (参加者向け: 月1,000〜3,000円)、イベント主催者向け手数料 (参加費の10%)。推定: 1都市あたり月20〜50グループ×平均5人×月2,000円 = 月20〜100万円規模の都市で月10〜20万円到達可能

個人での攻め筋（本人＋Claude）

1都市 (例: 東京・渋谷) に絞って立ち上げ、地域コミュニティを手動でブートストラップする (知人数十人への招待)。マッチングロジックはClaudeで開発し、参加費の1割 + 月額サブスク (月1,500円×50人)で月15万円レベルを目指す。その後、他都市への横展開を自動化する。

構築難易度 — 2/5

マッチングロジックとイベント管理画面はClaudeで実装可能。既存の地図API・カレンダー・決済APIを組み合わせるだけで、MVP段階では十分に構築できる。

想定技術スタック

Node.js + Next.js (フロントエンド・バックエンド)PostgreSQL (ユーザー・グループ・イベントDB)Stripe API (決済)Google Maps API (地域マッチング)Twilio / SendGrid (通知)Vercel (ホスティング)

片手間運用性 — 4/5

マッチングは自動化、ユーザーサポートはメール・チャット自動応答、イベント連絡もテンプレート化できる。初期ブートストラップ期は人手がいるが、基盤ができれば週5時間以下で回る。

収益到達性（月20万） — 4/5

ニッチながら、副業・起業志向の層は高い確度で月数千円を払う。また、企業の研修・新人育成向けのB2B展開 (法人向け月10,000円×3社程度) で月30万到達が現実的。
