なぜ流行っているか

開発業務の『見える化』とゲーミフィケーション。AI開発者コミュニティで親友的存在。Claude使用率向上のモチベーション工学。

中核機能

  • Claude API トークン消費の可視化
  • トークン量でペット成長(進化)
  • デスクトップウィジェット・かわいいUI
  • 成長ログ・統計表示

収益モデル

基本無料+有料版(カスタムペット・特殊エフェクト・クラウド同期)月500円。またClaudeへのアフィリ(新規ユーザ獲得)で手数料。

個人での攻め筋（本人＋Claude）

Claude ユーザ層(Reddit r/ClaudeAI, Twitter Claude開発者など)で『かわいいペットがトークン消費で成長』という遊び心で認知。基本無料で口コミ広がり、有料版(ペット種類追加・クラウド同期・統計エクスポート月500円)で月5~10%の課金化。ユーザベース1,000人中50人が月500円 = 25,000円。ただし単価が小さいため、企業向け(企業内Claude利用の『チームペット』機能)で月3,000円ライセンスを法人営業。月1社で3,000円。個人+法人で月30,000円程度。ただし市場規模(Claude愛好家)が限定的なため、スケール天井は低い可能性。

構築難易度 — 2/5

Claude API の integration 自体は簡単(公式SDKを使い、トークンカウント取得のみ)。ペット成長ロジックはシンプルなゲーム機構。デスクトップアプリ化(Electron等)も定型的。Claudeで 1~2週間で組める。唯一、『かわいさ』のUIデザインで手間。

想定技術スタック

Claude API (トークン取得)Electron (デスクトップアプリ)React (UI)SQLite or PostgreSQL (ペット状態DB)Tauri (軽量アプリ化)

片手間運用性 — 5/5

ほぼ完全自動。Claude APIのデータを取得し、DB保存し、ペット表示するだけ。ユーザサポートも最小。本業の片手間どころか、ほぼ放置でOK。

収益到達性（月20万） — 2/5

Claude ユーザという限定層(数万人程度)が対象。月500円の課金層は少ない(3~5%)。個人では月20万に届きにくく、法人営業で補う必要あり。ただし粘着度は高い(毎日見るペット)。
