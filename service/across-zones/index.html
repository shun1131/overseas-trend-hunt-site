なぜ流行っているか

リモートワーク・国際協業の標準化で、時間帯調整の煩雑さが常態化している。本サービスは「会議時間を URL に埋め込む」ことで、メール往復を排除する斬新さが評価されている。

中核機能

  • 複数タイムゾーンの同時表示
  • URL エンコーディング (設定が URL に埋め込まれ、共有可能)
  • 時間帯のビジュアル表現 (グリッド / 円形)
  • クイック開催時間提案

収益モデル

基本無料 + プレミアム (API アクセス・カレンダー連携・チーム管理、月500円程度)、または法人向け (会議予約システムとの統合、月3,000円)。推定: 少数の課金チーム (100社×月3,000円) で月30万円到達可能

個人での攻め筋（本人＋Claude）

無料版で B2B 営業マン・リモートチーム向けにバイラル獲得。法人向けプレミアム (月500〜3,000円) で営業チーム・HR 部門に営業。月 50〜100 社の課金で月 25〜30 万円到達。初期は Twitter・Product Hunt での告知で獲得。

構築難易度 — 1/5

タイムゾーン変換と URL エンコーディングは標準ライブラリで可能。フロントエンドも簡潔で、Claudeが 1 週間で完成させられるレベル。複雑な機能は不要。

想定技術スタック

Vue.js または React (フロントエンド)Node.js + Express (バックエンド軽量)moment-timezone / Day.js (タイムゾーン処理)Vercel (ホスティング)Stripe (プレミアム決済)

片手間運用性 — 5/5

完全に自動化・放置可能。ユーザーサポートはほぼ不要で、API メンテナンス程度で足りる。スケールしても計算コストは軽微。

収益到達性（月20万） — 4/5

B2B SaaS として課金導線が明確。リモートワーク化のトレンドで継続ユーザーが付きやすい。少数の課金企業でも月20万到達が容易。
