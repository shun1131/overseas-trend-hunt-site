なぜ流行っているか

ソロファウンダーの片手間開発で注目を集め、個人的でリアルな体験シェアのニーズが高い。SNS疲れからの『本物』指向層が反応

中核機能

  • パスシェアリング（地図上に個人ルートを記録・公開）
  • 複数スポットの時系列ガイド
  • ユーザー発見機能（近くのルートを表示）
  • コメント・評価機能

収益モデル

フリーミアムで基本閲覧は無料、プレミアムルート作成・分析機能は月課金。マイクロペイメント(作者への投げ銭)仕組みも

個人での攻め筋（本人＋Claude）

食べ物好きコミュニティ(Reddit r/food等)で『実際に歩いた食べ歩きルート』の投稿を促進。初期ユーザーは無料招待。地域別イベント(東京グルメ散歩など)で盛上げ、プリミアム化で月数千円課金へ

構築難易度 — 2/5

Google Maps API + Node.js/Next.js で容易に実装可能。リアルタイム同期もシンプル。ユーザー獲得・信頼構築が主な課題
