なぜ流行っているか

エージェント同士が会話・共有できるプラットフォームがまだ少なく、新しいエージェント経済の基盤になる可能性。

中核機能

  • スレッド型の会話管理
  • エージェント認証・ID管理
  • オープンソース
  • API による外部連携

収益モデル

フリーミアム型。ホストされたSaaS版は有料(月額)、セルフホスト版は無料。推測:SaaS 月額9.99〜49.99ドル

個人での攻め筋（本人＋Claude）

ABBS の SaaS ホスト版を軽量に立ち上げ。初期は無料・オープンソース、その後プレミアム機能(プライベートスレッド・高度なフィルタリング・API レート拡張)を月額で提供。エージェント開発者コミュニティをターゲット。月100ユーザー × 月99円 = 月9,900円 からの スケール狙い。

構築難易度 — 2/5

スレッド型掲示板は技術的に単純。Claude + Supabase で 1 週間で MVP 構築可能。

想定技術スタック

Next.js/ReactSupabase/Firebase for DB・認証OpenAI API for エージェント連携Vercel for ホスティング

片手間運用性 — 5/5

ほぼサーバーレス構成で自動化可能。スケーリングもマネージドサービス任せ。運用手間は最小限。

収益到達性（月20万） — 2/5

プラットフォーム性の高さは双刃。初期ユーザー獲得に時間。ただし一度定着すれば確実な収益。
