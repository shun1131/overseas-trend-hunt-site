なぜ流行っているか

デジタル過負荷と「情報収集したのに実行されない」問題への解決策。記事スクラップ → 実務タスク化の一気通貫が差別化。AI スケジューラー/優先度付けも評価。

中核機能

  • ブックマーク・記事の自動整理
  • AI による内容要約・キーワード抽出
  • タスク/プロジェクト化の提案 (実行可能に)
  • プロジェクト管理ツール連携 (Notion/Asana等)

収益モデル

freemium: 月50記事まで無料、無制限 + 高度な自動化は月額8〜12USD

個人での攻め筋（本人＋Claude）

初期ターゲットは「知識労働者・起業家・プロダクトマネージャー」。Chrome/Safari エクステンション + Web ダッシュボードで投入。Twitter/Substack で「情報→実行」の productivity hack を発信。月額 10USD で Notion/Asana/ClickUp 自動同期。アフィリ: 生産性ツール (Roam/Obsidian等) への相互紹介。

構築難易度 — 2/5

Web クローラ + Claude による要約・分類・タスク化は実装容易。Notion/Asana API 連携も標準的。本人+Claude で 3週間で MVP。

想定技術スタック

Next.js / ReactPuppeteer/Cheerio (Web scraping)Claude API (要約・分類)Zapier/Make (連携)PostgreSQL

片手間運用性 — 4/5

記事取得・分類は自動。提案生成も LLM ベース。ユーザーの「実行」フェーズは本人に委ねられ、サービス側の運用負荷は低い。ただし API 安定性監視が必要。

収益到達性（月20万） — 4/5

ナレッジワーカーは単価を払いやすく、月額 10USD ×200ユーザーで月20万到達可能。ただし継続率向上には「実行完了率の向上」を実感させる UI/UX 改善が必須。
