なぜ流行っているか

プライバシー重視・クラウドなしで自分のブラウジング履歴を検索可能。データ所有欲とプライバシー意識の高まりに呼応。

中核機能

  • ローカル全文検索（訪問ページ・キャッシュ）
  • プライベートサーバー（クラウド無し）
  • 複合検索オプション
  • ブラウザ拡張統合
  • CLI インターフェース

収益モデル

オープンソース無料 → ホスティング/SaaS 化（月額）、エンタープライズサポート

個人での攻め筋（本人＋Claude）

OSS 版を GitHub で公開し、スター稼ぎ・コミュニティ形成。6ヶ月で「クラウドホスト版」を SaaS 化（月 $9.99/$29.99）。プライバシー重視層を訴求点に「お金を払って自分のデータを自分のサーバーに置く」ビジネスモデル。月200～300 Pro ユーザーで月6～10万狙い。後付けで API 提供（開発者向け）で上乗せ。

構築難易度 — 2/5

全文検索エンジン（Elasticsearchやsqlite fts）、ブラウザ拡張、CLI 実装が必要。複雑だがClaudeで段階的に構築可能。

想定技術スタック

Python/Node.jsElasticsearch or SQLite Full-Text Searchブラウザ拡張APIVue.js or React（UI）Docker（デプロイ）

片手間運用性 — 4/5

ローカル構築後はほぼ放置可能。有料 SaaS 化する場合は課金管理が別途必要だが技術的には自動化可。

収益到達性（月20万） — 3/5

ニッチ（プライバシー重視・テック層）。月 $29.99 × 300 ユーザー＝月9,000ドル相当だが、ユーザー獲得に時間がかかる。
