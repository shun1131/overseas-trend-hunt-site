なぜ流行っているか

太陽光パネル普及拡大とサステナビリティ意識高まりで、自分の発電量を可視化したい需要が強い。

中核機能

  • リアルタイム発電量表示
  • 日別・月別・年別統計
  • CO2削減量換算
  • 天気連動予測

収益モデル

フリーミアム + プレミアム (詳細データ・レポート・最適化提案)。月3~10ドル。または、ソーラーパネルメーカー (Tesla/Sunrun等) へのB2B販売。推定初期: 月200~400ユーザー×6ドル=月1,200~2,400ドル。

個人での攻め筋（本人＋Claude）

ソーラーパネル所有者 (米国・欧州・日本の太陽光家庭) へターゲット。初期はSolarEdge/Enphase ユーザー限定、段階拡大。月500~800ユーザー×6ドルで月3,000~4,800ドル (月36~58万円)。B2B (パネルメーカーへの統合サービス提供) で+5~10万円。SEO: 『太陽光発電 可視化』『発電量管理アプリ』など。

構築難易度 — 3/5

ソーラーシステムのAPI接続 (Enphase/SolarEdge等) が必須。Claudeでバックエンドとモバイルアプリ組めるが、各メーカーAPI仕様習得に手間。

想定技術スタック

React Native/Flutter (モバイルアプリ)Node.js (バックエンド)Weather API (Dark Sky等)ソーラーシステムAPI (Enphase Connect/SolarEdge API)

片手間運用性 — 4/5

一度API統合すれば、データ取得・計算はほぼ自動。プッシュ通知・予測更新で最小限の手作業。

収益到達性（月20万） — 4/5

ソーラーユーザーの購買力は高く、月5~10ドルは痛くない。ニッチだが固い。月20万超えは十分可能。
