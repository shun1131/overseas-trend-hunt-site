なぜ流行っているか

音声AI × ToDoList の組み合わせが注目。ハンズフリー作業中に「やることを話す」という直感的UXが人気で、ProductHunt でも話題。

中核機能

  • 音声→テキスト自動変換
  • 意図推定で自動分類・予定化
  • 確認型フロントエンド (やることを聞き返す)
  • カレンダー・リマインダー連携

収益モデル

freemium: 基本無料 (月10〜30タスク) 、無制限 + 高度な同期は月額5〜8USD

個人での攻め筋（本人＋Claude）

初期ターゲットは「移動中・運転中・料理中など、テキスト入力が困難な場面」。iOS/Android の無料版を先行配布。Twitter/TikTok で「ながら作業」シーンでのデモ動画を拡散。月額 6USD のプレミアムで、複数端末同期・AI提案機能・Slack統合。ユーザーが「朝から晩まで何度も使う」体験を作る。

構築難易度 — 2/5

Whisper + Claude で音声→構造化 (タスク/期日/優先度) は実装容易。カレンダー・リマインダー連携も既存API。本人+Claude で 2〜3週間で MVP。

想定技術スタック

Next.js + React Native (iOS/Android)Whisper/OpenAI AudioClaude API (意図解析)Firebase/VercelGoogle Calendar API

片手間運用性 — 5/5

完全自動。音声入力後の処理は全クラウド。ユーザーは話すだけ。運用は統計分析・UX改善ループのみ。

収益到達性（月20万） — 4/5

日常的に使用頻度が高く、継続率が高い SaaS。月額 5USD ×400ユーザーで月20万到達可能。モバイルアプリの認知と ASO (App Store Optimization) に手間がかかるが、一度ユーザーが増えれば紹介で加速。
