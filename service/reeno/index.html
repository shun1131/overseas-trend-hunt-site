なぜ流行っているか

サプライズの電話介入で習慣化を強制。遊び心のある言語学習アプリが新トレンド。

中核機能

  • ランダム電話コール機能
  • 自動音声生成
  • 会話内容の復習ログ
  • レベル調整

収益モデル

フリーミアム (無料でランダムコール月3回 + 月額$4.99で無制限)

個人での攻め筋（本人＋Claude）

初期版は英語→日本語の1方向。月3回無料コール、有料会員月4.99ドルで無制限コール + 言語追加(中国語・スペイン語など)を段階リリース。TikTok/YouTube Shortsで「突然電話が…」というバイラル動画を製作し、口コミ拡大。言語学習層のコミュニティに浸透。月300〜400ユーザーで月商20万到達。

構築難易度 — 2/5

Twilioなどの電話APIで自動発信 + TTS + 音声認識を統合するだけ。UI/UXは軽量。Claudeが完全に構築できる。

想定技術スタック

Twilio (電話API)Google Cloud TTS/STTClaude API (会話生成)Node.js/Python スケジューラ

片手間運用性 — 5/5

電話インフラは外部APIで完全アウトソース。スケジュール実行・音声処理も自動。ユーザーサポートはメール程度。

収益到達性（月20万） — 4/5

ユニークな体験で口コミ性が高く、新規獲得コスト低い。習慣形成で継続率も期待できる。月4.99ドル×400人 = 月商20万の達成感度は高い。
