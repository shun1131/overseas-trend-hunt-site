なぜ流行っているか

プライバシー重視・オフライン対応の音声処理ニーズが急増。クラウド依存からの脱却志向が強い。

中核機能

  • ローカル実行（オンデバイス処理）で Whisper 並みの精度
  • 複数言語対応
  • API ライブラリとしての再利用可能性

収益モデル

オープンソース基本＋商用ライセンス（$99/年）、SaaS ホスティング版（$9.99/月）、企業向けカスタマイズサポート

個人での攻め筋（本人＋Claude）

無料オープンソース版で認知度獲得、次に SaaS ホスティング版（月$9.99）と商用ライセンス（年$99）の 2 層販売。月 100 ユーザーの SaaS + 月 50 社の商用ライセンスで月20万超達成。

構築難易度 — 3/5

音声処理の機械学習モデル最適化が必要で、完全な自作は困難。ただし既存の Whisper ベースモデルを活用・ラッピングすれば Claudeで実装可能なレベル。

想定技術スタック

Python（ML）Whisper/OpenAI API の活用Docker/Kubernetes（ホスティング）Node.js/Flask API

片手間運用性 — 4/5

オープンソース公開後、GitHub Issues 対応がメイン作業。SaaS ホスティング版は API サーバーの監視が必要だが手間は軽微。

収益到達性（月20万） — 4/5

プライバシー志向の企業が増える中、ローカル音声処理の価値は高い。商用利用の敷居が低く、ニッチながら確実な需要。
