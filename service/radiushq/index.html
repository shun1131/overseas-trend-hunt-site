なぜ流行っているか

会議スケジューリングの煩雑さは永続的課題で、Calendly など既存ツールも数多いが、「複数人の調整を 1 リンク + 1 回の操作で完結させる」シンプルさが注目されている。リモートワーク標準化に伴い、スケジューラーの DX ニーズが高まっている。

中核機能

  • 複数人の可用性を同時表示
  • 1 リンク共有 (会議調整ページ)
  • 自動カレンダー連携 (Google / Outlook)
  • タイムゾーン自動調整

収益モデル

基本無料 (月 5 予定まで) + プレミアム (無制限予定・カスタムブランディング・チーム管理、月 600 円程度)。法人向け (10 人チーム向け、月 3,000 円)。推定: 月 1,000 プレミアムユーザー + 50 社の法人で月 20〜25 万円

個人での攻め筋（本人＋Claude）

無料版で B2B 営業・採用担当者向けにバイラル獲得。チーム向けプレミアム (月 600 円) + 法人営業で月 50 社獲得を目指す。月 50 社×月 3,000 円 = 月 15 万円、プレミアムユーザー月 1,000 人×月 600 円 = 月 60 万円の二層構造で月 25〜30 万円到達。

構築難易度 — 1/5

Google Calendar / Outlook API を使った可用性表示は標準的。スケジューリングロジックも既知。UI/UX は最小限でよく、Claudeが 5 日で MVP 完成可能。

想定技術スタック

Next.js (フロントエンド)Node.js + Express (バックエンド)Google Calendar API / Microsoft Graph (カレンダー連携)PostgreSQL (ユーザー・予定 DB)Stripe (決済)Vercel (ホスティング)

片手間運用性 — 5/5

完全自動化・放置可能。API メンテナンスのみで、ユーザーサポートは FAQ で対応。スケール後も計算コストは軽微。

収益到達性（月20万） — 4/5

Calendly 等の競合と比較して、シンプルさが勝ち。B2B SaaS の課金導線が明確で、チーム単位での導入が期待できる。
