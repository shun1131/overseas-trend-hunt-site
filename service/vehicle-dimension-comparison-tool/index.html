なぜ流行っているか

電動車普及・自動運転普及に伴い、新しい車選びのリサーチが増加。従来のスペック表では比較しづらい「実際のサイズ感」を視覚化するニーズが高まっている。DIY・ガレージ活動層にも需要が見える。

中核機能

  • 複数車種の同時表示・スケール比較
  • 寸法の正確なデータベース
  • フィルタリング (車種・メーカー・価格帯)
  • 3D ビジュアル (オプション)

収益モデル

基本無料 (広告・メーカー提携) + プレミアム (広告非表示・詳細 CAD データ・比較エクスポート、月 300 円)。メーカー向け API (ディーラー向け可視化ツール)。推定: 月 5,000 ユーザー×広告CPM + 月 50 社メーカー API で月 15〜20 万円

個人での攻め筋（本人＋Claude）

初期は自動車ブログ・YouTube チャンネル経由でのバイラル狙い。Google 検索「車 サイズ 比較」「電動車 寸法」での SEO 確保。月 5,000 ユーザー×プレミアム課金率 10%×月 300 円 + 広告月 10 万円で月 20〜25 万円到達。

構築難易度 — 2/5

車のサイズデータ (Wikipedia・公式スペック) は公開情報。2D/3D ビジュアルは Three.js か Babylon.js で実装可能。Claudeで2週間で MVP 完成。
