なぜ流行っているか

言語学習の個別化AI需要が加速。ChatGPTやDuolingoと異なり、『個人に合わせて学習曲線を最適化』という人間的アプローチが評価。ニッチ言語対応の可能性も高い

中核機能

  • 個人学習履歴に基づくAIカスタマイズ
  • リアルタイム発音フィードバック
  • 毎日の学習進捗最適化

収益モデル

推定:サブスク月9.99ドル(基本パスポート)、月19.99ドル(プロ・高度なフィードバック)

個人での攻め筋（本人＋Claude）

特定言語(日本語、中国語、アラビア語など発音が難しい言語)に特化。Udemyや言語学習コミュニティへの提携・アフィリ。月9.99ドルで月10000ユーザー×5%課金=月5000ドル(月50万円)。初期段階では月1000〜2000ユーザーで月10万円から開始し、1年で月20〜30万円達成を目指す

構築難易度 — 2/5

音声API(Google Cloud Speech-to-Text)・言語モデル統合(Claude API)・学習トラッキングDB設計はClaudeで可能。既存発音評価ライブラリ活用で短期実装

想定技術スタック

React NativeGoogle Cloud Speech-to-TextClaude APIPostgreSQLStripeTwilio

片手間運用性 — 3/5

ユーザーサポート・カスタマイズリクエストが月に数件~数十件発生。自動化できないが、対応時間は限定的。自動化チャットボット(Claude)で軽減可

収益到達性（月20万） — 4/5

言語学習市場は大きく、月9.99〜19.99ドルの価格設定は業界標準。月5000ユーザーで月20万円超は十分達成可能。ただし初期ユーザー獲得に3〜6ヶ月要する
