なぜ流行っているか

AIと手書き学習の融合で、従来の静的な描画教材と異なる新しい学習体験として注目を集めている。

中核機能

  • ステップバイステップの描画ガイド
  • リアルタイムフィードバック
  • 幅広い描画対象（動物・風景・キャラクター等）

収益モデル

freemium (基本無料＋プレミアム月額、またはアフィリ)

個人での攻め筋（本人＋Claude）

初期は「動物10種類」など限定コンテンツで無料提供し、TwitterやTikTokで学習ビフォーアフター動画で集客。月額$2.99のプレミアム（フル300コンテンツ）で月100～150人が無理のない規模。UI/UX改善と新ジャンル追加を段階的に。

構築難易度 — 2/5

Claudeと本人でCanvas描画API、段階的UIロジック、簡易的なAIフィードバック（又は静的チェック）を構築可能。特殊なモデル学習は不要。

想定技術スタック

React / Canvas APIClaude APINext.jsVercel

片手間運用性 — 4/5

コンテンツ（描画ガイド）は一度作成すればほぼ固定。ユーザーサポートや新コンテンツ追加は最小限で運用可能。

収益到達性（月20万） — 4/5

描画学習は恒常的需要がある（子ども～成人）。freemiumモデルで月150人×$2.99で月$450程度。複数言語展開やYouTubeアフィリで加速可能。
