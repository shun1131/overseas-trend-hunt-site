なぜ流行っているか

気候変動・庭のサステイナビリティへの関心の高まりと、LLM活用による「個人向けパーソナライズ」の融合。アメリカ地域ごとの自然志向ユーザーに需要。

中核機能

  • 位置情報ベースのネイティブ植物推奨
  • エコシステム情報 (野生動物・受粉者への効果)
  • 庭のレイアウト提案
  • ローカル園芸ガイドとの連携

収益モデル

freemium: 基本無料、詳細レポート・設計図は有料、またはアフィリ (園芸店・種子業者向け)

個人での攻め筋（本人＋Claude）

初期は1〜2地域 (例：カリフォルニア、シアトル周辺) に絞り、ローカルネイティブプラント協会と連携して信頼性を確保。庭の写真アップロード → ネイティブ植物レコメンデーション → ECサイト (園芸店) へのアフィリで収益。SNS (Instagram/Pinterest) で庭改造ビフォーアフター事例を発信。月額 5〜10USD のプレミアムプランで詳細設計図を提供。

構築難易度 — 3/5

ネイティブ植物データベース構築に手間。初期は既存OSM/GBIF等のオープンデータ活用で軽減できるが、精度と地域カバレッジを高めるには業者データやクラウドソースが要る。

想定技術スタック

Next.js / ReactClaude API (LLM推奨エンジン)Geolocation APIMapbox or OpenStreetMapPostgreSQL + PostGIS

片手間運用性 — 3/5

コアアルゴリズムは自動実行。ただし植物DB更新・ユーザーフィードバック反映・ローカル園芸家との関係構築に定期手間がかかる。

収益到達性（月20万） — 3/5

米国の環境配慮ユーザーは単価を払いやすいが、初期段階では地理的リーチが限定。月20万到達には 300〜500有料ユーザーと広告・アフィリの複合が要る。成長には時間がかかるが、長期的にはSEO効果が高い。
