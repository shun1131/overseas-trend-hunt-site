なぜ流行っているか

GitHub Issue の再現テストが開発者の最大の手作業負荷。AI Agent でこれを自動化する需要が急速に高まっている。

中核機能

  • Issue 説明からの自動再現実行
  • 再現ステップの自動生成
  • デバッグ情報の自動収集
  • PR 自動生成（簡易修正の場合）

収益モデル

フリーミアム：月10 Issue 無料、プレミアム月額499円（無制限＋PR 自動生成＋チーム管理）

個人での攻め筋（本人＋Claude）

初期は特定言語（Python・JavaScript）に特化し、人気リポジトリに無料提供で事例を集める。成功事例を PR・ブログで発信。プレミアム版で言語拡大・自動 PR 生成。月額499円×100〜150 ユーザーで月20万到達。GitHub Marketplace での認知拡大も活用。

構築難易度 — 3/5

Issue テキストから実行環境を推測し、コード実行・ロギング・デバッグ情報取得を自動化する必要あり。環境依存性が高く、複数言語対応に手間。

想定技術スタック

Claude API（Issue 解析・実行計画生成）GitHub APIDocker（テスト環境の隔離実行）言語別テストランナー

片手間運用性 — 2/5

ユーザーのリポジトリ設定・環境による失敗が多く、サポート負荷が高い。初期段階では手動修正・対応が常時必要。

収益到達性（月20万） — 3/5

B2B2D（企業向け開発ツール）で課金が見込めるが、環境依存性とサポート負荷が大きいため、到達難易度は中程度。
