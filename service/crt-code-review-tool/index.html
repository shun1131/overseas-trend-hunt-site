なぜ流行っているか

AI生成コードの品質チェックが急務となる中で、開発者が負担なくレビュー・修正サイクルを回せるツールとして関心が高まっている

中核機能

  • AI生成コードの段階的レビューUI
  • 修正部分のみ再生成・反復対応
  • レビュー履歴の記録・比較

収益モデル

オープンソース基盤。有料版はVSCode拡張として月額制（月299円程度）、またはSaaS化による従量課金（月2,000〜5,000円）と推定

個人での攻め筋（本人＋Claude）
