なぜ流行っているか

Claudeなど複数 LLM の並行利用が増え、コード生成フェーズごとのコスト把握ニーズが急速に高まっている。

中核機能

  • LLM API 呼び出しの自動トラッキング・分解表示
  • コード生成フェーズごとの時間・コスト分析
  • 複数 LLM 間のコスト比較・最適ルーティング提案

収益モデル

SaaS 月額（基本 $4.99/月、プレミアム $14.99/月）またはダッシュボード API 従量課金

個人での攻め筋（本人＋Claude）

Decant と同様に開発者コミュニティを主ターゲット。AI コーディングの利用増加に乗じて月 200～300 ユーザーの $10 平均課金で月20万達成を狙う。差別化は複数 LLM 比較機能と最適ルーティング提案。

構築難易度 — 1/5

LLM API ログの集約・分析・可視化が主体で、Claudeが単独で容易に構築可能。技術的障壁が低い。

想定技術スタック

Node.js/Python backend複数 LLM API（Claude/GPT等）データベース（PostgreSQL等）React/Vue フロントエンド

片手間運用性 — 5/5

API トラッキング基盤が自動で、ダッシュボード表示のみ。新規 LLM 対応が定期必要だが作業量は軽微。

収益到達性（月20万） — 4/5

開発者向けで課金率が高く、API 費用削減の直接的価値が訴求しやすい。Decant との競合を避けるため複数 LLM 比較に特化すれば差別化可能。
