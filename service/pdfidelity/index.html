なぜ流行っているか

多言語PDF翻訳はビジネス実務で日常的需要。既存翻訳サービスより『レイアウト維持』が差別化ポイント。

中核機能

  • PDF読み込みと言語自動検出
  • レイアウト・フォーマッティング保持したまま翻訳
  • 複数言語対応、バッチ処理

収益モデル

推定:従量課金(1ページ10〜50円)またはサブスク月額(月1,500〜5,000円、毎月100〜500ページ)

個人での攻め筋（本人＋Claude）

『無料で3ページまで試用→月2,000円で100ページ/月』のサブスク化。B2B法人営業では『翻訳単価:1ページ30円×平均月500ページ=月1.5万円×15社』で月22.5万円。初期は法人パイロット導入に注力。

構築難易度 — 2/5

PDFパース+翻訳APIの組み合わせはClaudeで十分構築可能。既存ライブラリ(pdfplumber, pypdf等)活用で労力削減。

想定技術スタック

PDF.js/pdfplumber (PDFパース)Claude API (翻訳)React (フロントエンド)FastAPI/Flask (バックエンド)

片手間運用性 — 5/5

ユーザーアップロード→自動処理→ダウンロード。完全自動化でき、常駐ゼロ。スケーリングはクラウド側の設定のみ。

収益到達性（月20万） — 5/5

PDF翻訳は企業・大学・出版社から継続的な課金が確実。少ない顧客数でも月20万到達しやすい。
