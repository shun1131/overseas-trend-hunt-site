なぜ流行っているか

LLM API呼び出しのコスト削減と『エージェント内の記憶保持』が開発者の新しい課題。既に実装されている複数エージェント開発フレームワークで採用が進んでいる

中核機能

  • エージェント内コンテキスト永続化
  • トークン最適化・再利用機構
  • 複数エージェント間のメモリ共有

収益モデル

SaaS型。基本無料・フリーミアム（月10万トークンまで無料）、月額19ドル〜99ドル（トークン上限解除・優先度）と推定

個人での攻め筋（本人＋Claude）

開発者向けに月額29ドル『プロフェッショナルプラン』（月100万トークン）を設定。AIエージェント製作者の急速な成長を背景に、エージェント開発の『スタンダード基盤』として採用を促進。月300ユーザー×月29ドル = 月8,700ドル（約130万円）から開始し、月額79ドル『エンタープライズ』へのアップセルで月20万達成

構築難易度 — 2/5

メモリ管理はデータベース（PostgreSQL/Redis）で実装。エージェント間通信はREST API + キューイングで対応可能。Claudeのエージェント実装も十分対応可

想定技術スタック

Node.js/PythonPostgreSQL/RedisAPI GatewayDocker

片手間運用性 — 5/5

完全自動化可能。ユーザーが使用したトークン数をカウント・課金するのみ。スケーリングは従量課金なので負担小

収益到達性（月20万） — 4/5

エージェント開発者の月額予算が高く（年100〜500ドル）、月29ドルは導入しやすい。フリーミアムから有料移行率も高い
