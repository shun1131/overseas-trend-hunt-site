なぜ流行っているか

開発者が無数のサイドプロジェクトを立ち上げては放置する現象に対し、「どのプロジェクトがまだ生きているか」を可視化する遊び心のあるアイデア。

中核機能

  • プロジェクト登録と最終更新日の追跡
  • 生存状況の自動判定表示
  • プロジェクト検索・フィルタリング
  • デベロッパー向けコミュニティ機能

収益モデル

フリーミアム：基本無料、プレミアム月額99〜199円（カスタム通知・詳細分析・API アクセス）

個人での攻め筋（本人＋Claude）

初期は無料で展開し、Hacker News・Reddit・Product Hunt での自然シェア。デベロッパー向けのユーモアとメタ感で拡散。プレミアム版で Slack 連携・カスタム通知。月1万PV 達成後、コンバージョン3〜5％で月20万。API 版（企業向け）で追加収益。

構築難易度 — 2/5

GitHub API でプロジェクト情報を自動取得し、最終更新日から生存状況を判定。シンプルなメタデータ管理で Claude で十分。

想定技術スタック

片手間運用性 — 5/5

GitHub API のポーリングと定期更新で完全自動化。運用はほぼ不要。バイラル性が高く、初期は PR・クチコミで拡散。

収益到達性（月20万） — 3/5

ターゲットはデベロッパーで、課金意識が比較的低い層。ただし自然シェア率が高く、月1万PV で月20万に到達可能。ニッチだが固定ファンが見込める。
