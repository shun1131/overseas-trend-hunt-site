なぜ流行っているか

AI コーディングエージェントで作成したプロダクトを直接販売できるプラットフォーム。個人開発者の AI 活用の新しい収益化形態として注目。

中核機能

  • ワンクリック発行・販売
  • コード・Web アプリ・ツール販売対応
  • 決済・配布自動化
  • 作者のレピュテーション管理

収益モデル

マーケットプレイス手数料(推定 20-30%)。Boonful の手数料を差し引いた売上が個人開発者に返金。初期段階では手数料率を優遇。

個人での攻め筋（本人＋Claude）

Boonful はプラットフォーム型だが、個人が副業 SaaS として活用するなら、『AI 生成ツール専門マーケットプレイス』として日本特化版を開発。初期は Gumroad や Lemonsqueezy との差別化として『Claude Code 製品向け特化』を打ち出す。自分自身も複数の小ツールを販売しながら、他の開発者も招待。月20ツール×平均売上$500 = 月10万+プラットフォーム手数料で月20万達成。

構築難易度 — 2/5

マーケットプレイス基盤(決済・ホスティング・配布ロジック)の構築は中程度。ただし Stripe Connect + AWS Lambda でシンプル化可能。

マーケットプレイス手数料ビジネスは初期ユーザー獲得が課題だが、一度トラクションがつけば指数関数的増加。月20万は現実的。
