なぜ流行っているか

企業の会話分析需要は高いが、Gong は高額。OSS 代替への関心が高まっている。

中核機能

  • 会話録音・自動転写
  • セールス活動の主要指標自動抽出
  • トレーニング提案の AI 生成
  • エクスポート・統合 API

収益モデル

ホスト型 SaaS サブスク(月額49〜199ドル)、セルフホスト版無料。推測: per-seat or per-minute ベースの従量課金も可能

個人での攻め筋（本人＋Claude）

セールス・カスタマーサポート向けに、会話分析ツールの OSS + ホスト型 SaaS を提供。初期は特定業界(SaaS セールス)に絞り込み。API で Slack/Teams/CRM 連携。月額49ドル × 50 社 = 月2,450ドル(月24,500円)からのスケール狙い。SMB 対象で、営業不要の自然成長戦略。

構築難易度 — 3/5

音声認識・自然言語処理はClaudeで部分実装可能だが、 Gong クラスの精度・速度には専門 NLP モデル微調整が要る。ただし OSS ツールなら最初は簡易版で十分。

想定技術スタック

Next.js/ReactWhisper API or Deepgram for 音声認識Claude/GPT-4 for conversation analysisSupabase/PostgreSQL for データ保管Strapi or custom API for integrations

片手間運用性 — 3/5

ユーザー会話データの保管・処理が常に必要。ただしシステムは自動で回る。

収益到達性（月20万） — 4/5

セールス・カスタマーサポートは IT 予算持ちで、月50ドルの支払い意思が高い。
